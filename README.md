☕ Coffee Sales Dashboard

An interactive Excel dashboard analyzing coffee shop sales data to uncover revenue trends and customer behavior patterns.

* * *

## 📊 Project Overview

This project explores transactional sales data from a coffee shop, transforming raw records into actionable business insights using Microsoft Excel.

* * *

## 📁 Dataset

| Column | Description |
| --- | --- |
| `Date` / `Time` | Transaction timestamp |
| `hour_of_day` | Hour when the purchase was made |
| `Time_of_Day` | Morning / Afternoon / Evening |
| `Weekday` / `Month_name` | Day and month of transaction |
| `coffee_name` | Type of coffee purchased |
| `cash_type` | Payment method |
| `money` | Transaction value |

* * *

## 📈 Dashboard Views

* **Revenue by Month** — Track monthly sales performance and spot seasonal trends
* **Revenue by Date** — Day-level view to identify peak and low days
* **Sales by Time of Day** — Understand when customers buy most (morning rush vs afternoon)
* **Revenue by Coffee Type** — Which products drive the most income
* **Orders by Hour** — Breakdown of each coffee type ordered per hour of day

* * *

## 🔍 Key Insights

* **Latte** is the best-selling coffee type by revenue
* Identified peak sales hours to help optimize staffing and inventory
* Showed clear patterns in customer behavior across weekdays and months
* Total Revenue exceeded 112K+
* 3.5K+ customer orders analyzed
* Average Order Value: 31.56
